## Описание проекта

Лабораторная работа посвящена углубленному изучению базовых типов данных, работы со строками, массивами, а также ручной сборке проекта в исполняемый JAR-файл.

Все 8 заданий (и сборка) реализованы в виде отдельных классов. Главный класс `Main` вызывает консольное меню (Задание 8), через которое можно запустить любое из заданий.
